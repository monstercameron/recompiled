# Recompiled

An independent, source-linked index of video game decompilations, recompilations, and fan translations. SQLite in `data/catalog.sqlite` is the persisted catalog. GitHub Pages serves the static `docs/` site, whose interface and search are generated by Rust/WASM; a small JSON export bridges the database to the browser.

## Run locally

Install the stable Rust toolchain, the `wasm32-unknown-unknown` target, and `wasm-bindgen-cli` version `0.2.129`. Then:

```sh
./scripts/build.sh
python3 -m http.server 8000 --directory docs
```

Open `http://localhost:8000` in a browser. The site needs an HTTP server because it fetches its catalog and WebAssembly module.

## Catalog method

Entries are researched independently and verified against project-owned sources. Each project record includes direct links to its code or patch project and any progress or release references used to establish its status. Filters cover project type, platform, approach, stage, linked source type, translation language, and dates. “First found here” is when an entry entered this index; a project start date is shown only when a primary source provides one. Catalog records point to projects; they do not contain game ROMs or copyrighted game assets. Add reviewed records with `python3 scripts/catalog.py import path/to/records.json`, then run `python3 scripts/catalog.py export` or `./scripts/build.sh`.

## Publish

The Pages workflow builds the Rust/WASM search module and deploys the `docs/` directory on pushes to `main`. In the repository's Pages settings, select **GitHub Actions** as the build and deployment source.
