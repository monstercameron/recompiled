# Catalog hydration round 6 — 2026-10-16

This reviewed batch adds 358 projects and refreshes source-backed metadata for projects already in the 2,298-row catalog. It includes 327 broad decompilation, recompilation, API translation, reimplementation, emulator, and software targets; 18 fan-localization patches; 10 current cross-platform ports/API translations; and three software/firmware reconstructions. It applies 201 non-conflicting project patches and adds 384 current/explicitly unknown language-evidence records (358 additions and 26 existing projects). The [metadata audit](audit-notes.md), [additions audit](additions-audit.md), [fan-localization notes](fan-localization-notes.md), [cross-platform notes](current-port-research-notes.md), and [software research notes](software-research-notes.md) record source reconciliation, review-date conventions, no-ops, held leads, exclusions, patch formats, and disposable-database validation. The import inputs and machine-readable audits are kept here as the reproducible canonical manifests.

The patch bundle adds 94 source citations. New project records include a source-checked summary, method/strategy, current status, target platform, source availability, and repository language; all rows link to maintainer evidence. The language bundles replace or add evidence only where repository identity and GitHub Languages API results were checked; five empty maps among the broad additions and 12 localization entries with unavailable or empty maps are explicitly marked unknown. Fan-localization rows identify source and target language and link to patch releases or repositories; they catalogue patch projects only and do not include game images. Candidate patches for unresolved repository identity, duplicate/unchanged rows, or conflicting API snapshots remain held. The additions audit records unresolved project-license and release-endpoint cases rather than implying rights or release absence.
