# Emulator sweep — 2026-10-16

## Scope and method

This pass adds source-available software and FPGA emulator implementations across personal computers, minicomputers, Nintendo systems, PlayStation, synthesizer hardware, classic computers and arcade boards. I read `/Users/earlcameron/Desktop/recompiled/AGENTS.md`, checked the `import-emulators` importer shape, and used maintainers’ repositories, READMEs, release pages, license files, and GitHub repository/language APIs as primary evidence. The checked-in manifests are proposals only.

Before staging, I compared candidate IDs and canonical GitHub owner/repository identities against the current SQLite catalog (363 emulator records at review time), all `work/**/*.json` manifests and all `data/research/**/*.json` manifests. No staged row in this batch duplicates a current catalog project or an existing staged project addition. Three researched candidates were omitted because they are already represented in the catalog or staged research: [OP-1 Emulator](https://github.com/op1emu/op1emu) is in the catalog and staged additions; [Game.com MiSTer core](https://github.com/MiSTer-devel/GameCom_MiSTer) is in the catalog and a staged addition; [G2fresh](https://github.com/r0main-f/G2fresh) already appears in the existing emulator-round-2 search audit, so it was not resubmitted.

The Seibu Cup Soccer entry uses the original maintainer repository, [rmonic79/Arcade-SeibuCupSoccer_MiSTer](https://github.com/rmonic79/Arcade-SeibuCupSoccer_MiSTer), rather than the forked MiSTer-devel mirror. The original repository has the v1.0 release and the same implementation documentation.

## Status, language and rights notes

`updated` in each row is the GitHub `pushed_at` date, which records repository activity rather than a release or compatibility guarantee. Where a release exists, its published date and URL are included in the row sources. Older MiSTer cores are described as maintainer-documented implementations; the status wording preserves any known limitations and avoids implying current active maintenance.

`programming-languages.json` stores the exact byte totals from each official GitHub `/languages` endpoint on the review date. The predominant language is the largest byte count, not a measurement of the emulator core alone; these repositories include FPGA frameworks, build scripts, docs and reference material.

All emulator code licenses are repository-level evidence. BIOS, firmware, game ROMs, OS disks, tape images and included historic programs have separate rights. The row notes flag where the maintainer requires user-supplied firmware or where bundled assets lack a separate rights statement. No ROM, firmware, game data or other binary payload was downloaded or copied into this folder.

The only files staged here are importer-shaped emulator proposals, language-byte evidence and primary API snapshots for review. No database import or tracked-file edit was made by this sweep.
