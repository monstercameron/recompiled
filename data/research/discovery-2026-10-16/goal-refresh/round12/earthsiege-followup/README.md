# HERCULAN / Earthsiege 2 follow-up

A Reddit discussion surfaced HERCULAN; its maintainer repository was checked directly before inclusion. The README calls it a reverse-engineered full reimplementation of Earthsiege 2, reports beta status, documents Windows and Linux builds and supported retail releases, and says original game files are required and not distributed. GitHub’s latest release was v0.9.8, published 2026-10-16. The repository license is MIT, with an explicit exception for branding artwork. Exact GitHub language byte totals were captured from the Languages API.

The repository contains a related HercWorks CSharp data-tool suite; this is kept in the HERCULAN record rather than presented as a separate target project. One direct remote screenshot URI is included; no image or game asset was downloaded. The profile uses the Earthsiege 2 Wikipedia page for game facts and direct article linking; the project README independently confirms developer, publisher, and 1996 release year.
