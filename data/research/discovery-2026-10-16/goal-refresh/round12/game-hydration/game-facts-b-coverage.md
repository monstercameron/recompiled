## Source quality, validation, and unresolved records

The older console and PC-98 titles rely on the databases named in their evidence because a usable official product page or manual was not located. For the disputed exact dates, the importer file uses only the coarser date granularity supported by the consulted record or omits the date entirely. The `Selected Japanese visual novels from the 1990s` key is a multi-title project input rather than one identifiable retail game, so it intentionally has an empty fact list.

The JSON parses and contains exactly the 35 input keys, in input order, with no duplicates. All 52 distinct source URLs are well-formed HTTPS links. A direct fetch check succeeded for 22 URLs; 30 were blocked by source-site bot protection (HTTP 403/418), not reported as missing pages. The source links remain attached to each fact so they can be opened normally in a browser.
