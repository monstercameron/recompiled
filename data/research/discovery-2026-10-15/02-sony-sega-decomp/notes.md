# PlayStation and Sega/arcade research — 2026-10-15

This lane found nine distinct game targets for the existing catalog: seven PlayStation projects and two Dreamcast projects. Each candidate was checked against its own repository README and, where available, a project release or implementation guide. Status wording preserves the maintainers' limits: for example, Spider-Man 2 remains non-playable, Castlevania Chronicles v0.3.10 is still under full-game testing, MGS One's alpha.1 is explicitly untested, and Rogue Trip's reported gameplay is limited to menus and the first level on Linux. The OpenHuey README separately describes its functional decompilation/runtime and an incomplete actor rewrite.

Repository evidence was checked with GitHub's repository/readme endpoints, source trees, and release pages. For the Dreamcast decompilations, the README supplies supported disc revision identifiers and live function-progress reports. For the PS2 recompilations, the repository records identify the exact executable/disc build and whether a native run is playable. The candidate set does not include general-purpose tools, emulators, or source ports that lack a game-specific decompilation/recompilation claim.

The SQLite catalog was queried by project ID, canonical repository URL, repository root, game title, and version/target name before each addition. No existing entry matched these nine repository/target pairs. Burnout 3 already has an Xbox recompilation entry, so the new record explicitly identifies the distinct PS2 executable and target. Other discovery leads were not added where the repository lacked implementation evidence or had only a template/skeleton: the Sly 2 repository contains a README-only zero-progress project; the Sonic Adventure lead had no decompilation source tree; and several PSX recompilation repositories have generic scaffolding with no target-specific progress report.

The metadata audit contains 26 field corrections across existing rows. It favors exact regional serials, supported builds, current project-owned status, release/platform distinctions, source availability, and a missing subtype. A GitHub repository's creation date was not treated as a reliable project start date; no `project_started` value was added because the checked primary sources did not state a project-start date.

No catalog database, generated catalog JSON, build output, or other research lane was changed. The three files here are discovery manifests for review only.
