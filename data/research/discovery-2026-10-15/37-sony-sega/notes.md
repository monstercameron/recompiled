# PlayStation, Sega, and arcade discovery notes

Reviewed maintainer repositories and primary README/status/release pages for the candidate projects below, then checked IDs and canonical repository URLs against SQLite, docs/catalog.json, central reviewed additions, and all data/research JSON manifests. Only missing game-specific records are staged here. No import or catalog/database edit was made.

## Included

The additions are independent game/version projects with code or tools that perform an actual decompilation, recompilation, or native-port implementation. Status text is limited to behavior the project README or release evidence reports. The Sega Saturn projects use the shared saturnkit as a submodule, but each repository identifies its own game, executable/disc target, and game-specific port work. The Sega arcade records likewise separate each game-specific repository from its shared board runtime.

## Exclusions and deduplication

- The catalog already contains the Urban Reign PS2 recompilation, Dragon Ball Z: Budokai HD PS3 recompilation, Virtua Fighter 5 PS3 recompilation, and Resident Evil Code: Veronica X PS2 decompilation. Urban Reign, DBZ Budokai HD, and VF5 were therefore not proposed as new rows; the DBZ row has a source-backed status/summary refresh here. The decompilation and the new enhanced PC port of Code: Veronica X are distinct repositories and methods, so the port is a separate project record.
- Resident Evil 3: Nemesis (Project RE: Visited) is already present as a reviewed addition in the parallel 04-game-recomp manifest. The generic Sega Model 3 recompilation framework is already recorded in the reverse-tools lane; this batch adds only its distinct playable The Lost World: Jurassic Park game repository.
- Crazy Taxi has three distinct repository/build targets here: the existing Dreamcast matching decompilation, the PS3 PSN static recompilation (NPUB30242), and the Xbox 360 XBLA static recompilation (58410A34). These are different executables and platforms, not duplicate entries. The Simpsons Arcade PS3 PSN project (NPUB30563) is separate from the existing Xbox 360 XBLA recompilation. The new PS3 HD-remaster project for Shadow of the Colossus (NPUA80677) is distinct from the existing PS2 version record. The X JAPAN, Deep Fear, and Virtual Hydlide projects share saturnkit but target separate Saturn games and discs; each is retained once.
- The X post by Yoshino on 2026-10-04, quoted in the 2026-10-06 WarpZone article, describes Model 3 PC recompilation starting with The Lost World and names Virtua Fighter 3, Scud Race, Sega Rally 2, and Daytona USA 2 as future plans. No game-specific implementation repository or working recompilation was found for those announced future targets, so they are not cataloged as current projects. The primary discovery link is https://x.com/yoshinokentarou/status/2106876863394287784; the durable article is https://warpzone.me/projeto-recompila-o-sega-model-3-e-ja-roda-the-lost-world-jurassic-park-sem-emulador/.
- Fighting Force Recomp and Medal of Honor: Underground PSX Recomp are scaffold templates whose READMEs explicitly say they were generated with the new-project layout; no title-specific implementation evidence was found. The generic SaturnRecomp example/template and saturnkit itself are not game-specific ports and are not repeated here.
- No separate Scud Race record is included: the X/article item is an announcement of a planned future target, not evidence that the game already has a title-specific native port.

## Method and language notes

Every included record is backed by a primary repository README; release/status/API links are added where useful. GitHub's language endpoint is used for programming_language where available. A few repositories are reported by GitHub as CMake or Python because their tracked build/recompiler tooling dominates its language statistics even though the README describes generated C/C++ game code; those records retain the API value rather than infer a different dominant-language value. Project start dates are left blank because no reliable start date was established. first_found and updated denote this 2026-10-15 catalog review.
