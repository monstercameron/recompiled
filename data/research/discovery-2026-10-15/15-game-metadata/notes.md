# Game metadata research — 2026-10-15

Reviewed eight game targets with projects in the catalog and no existing game facts: Animal Crossing, Mario Kart 64, Star Fox 64, Diddy Kong Racing, Mario Kart Wii, Perfect Dark, Paper Mario, and Super Mario Strikers. The staged game-facts manifest contains 46 source-linked facts, including platform, genre, credited developer and publisher, regional date granularity, and verified regional title variants. Official Nintendo product pages are used where available; MobyGames is used as a reputable release/credits reference for the older Mario Kart 64 and Star Fox 64 records. Release dates are tied to the named territory or page listing rather than presented as a single global launch date.

The separate Wikipedia manifest replaces four existing Special:Search fallbacks with exact direct game articles for Star Fox 64, Perfect Dark, Paper Mario (video game), and Super Mario Strikers. The other four direct page links are included for consistency. All eight `game_key` values already exist in `games`.

Audited 37 project rows across those eight game targets for source version, platform, and maturity wording. The five staged project updates add source revision/region details directly supported by current project READMEs: Perfect Dark’s six ROM IDs and default; US-only Mario Kart 64 and Star Fox 64 static recompilation inputs; two supported Diddy Kong Racing revisions; and the US ROM hash plus physical-hardware evidence for the Mario Kart 64 Dreamcast port. Other rows in these selected groups already stated their supported target platform/source region or clearly qualified maturity, so no further changes were staged. No additional game-specific project targets were identified in the reviewed project-source set.

The profile importer accepts arbitrary fact fields, but the current UI has translated labels only for the existing canonical name, genre, platform, release date, developer, publisher, series, and collection-context fields. No custom source-language field was staged because the UI would label it as a generic name; language availability is retained in evidence text where official regional listings expose it. The regional date values make the source territory visible without inferring a ROM language from region alone.

Files are staged only; SQLite, generated catalog JSON, and build outputs were not touched.
