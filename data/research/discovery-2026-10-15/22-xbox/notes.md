# Xbox project research (2026-10-15)

Reviewed GitHub repositories, owner-authored READMEs and status documents, release pages, and repository metadata. Candidate discovery was deduplicated against the live `data/catalog.sqlite` (897 project rows at review) and every staged `new-projects.json` under `data/research/discovery-2026-10-15/`. No exact project repository URL or ID in this batch already existed, so `metadata-updates.json` is intentionally empty. The original manifest contains 39 target records: 24 individual Xbox/Xbox-derived projects and 15 title-specific ports/releases in the CrownPark Xbox 360 Native Ports collection. A separate `new-projects-round2.json` records five additional candidates from an expanded second GitHub search, preserving the original 39-row manifest. Each record has an HTTPS project source plus direct status, release, platform, conversion, or language evidence where available. Unknown support and maturity are called out in the row rather than inferred.

The CrownPark repository is a multi-title project with discrete per-game build/configuration trees and separate downloadable launchers. Rows use a title-specific ID and release URL. This intentionally records distinct implementation repositories for games that already have another catalog entry, including Banjo-Tooie XBLA, Daytona USA XBLA, Geometry Wars: Retro Evolved 2, Midnight Club: Los Angeles, and The Darkness. Those rows preserve project provenance and are not updates to the existing projects. The Darkness row points to `invinceble55-wq/Estacado-The-Darkness-Recomp`; the current catalog’s row points to `portingpete/The-Darkness-Recomp`.

The CrownPark README says all listed games are playable and documents Linux and Windows launchers. The source tree contains per-title conversion folders for the titles linked to `CONVERSION.md`. Three other released titles (Space Giraffe, OutRun Online Arcade, and Daytona USA) have public title-specific v1 release pages and appear in the README title table, but their per-title source folders were absent from the inspected `main` tree. Their `source_available` field records that limitation. After Burner Climax appears in the README table, but no title-specific release or source folder was found, so it is excluded pending stronger evidence. PGR4 exists in this repository’s tree but is not in the collection’s public title table or release list; the independently documented `beatrixzy/PGR4-Recomp` is the Xbox PC project entered here.

Other deduplication and interpretation notes:

- `danielgpinheiro/ccleste-xbox` and other GameCube/PC-to-console items are already staged in `25-pc-console`; the Xbox dashboard project is staged in `26-software-apps`; WinDurango is already in SQLite and its status update is staged in the software/API lane. They were not copied here.
- Tony Hawk’s Project 8 Switch recompilation is already cataloged; the `theokyr/Project8Recomp` record is a distinct Linux/macOS/Windows PC target.
- Burnout Revenge has multiple independent sources in this batch (Xerenge, Fabioap, and CrownPark). Their distinct repositories and reported maturity are preserved separately. Xerenge’s README names USA support from v0.4.7, while its latest published release checked was v0.4.6; the record flags this version mismatch.
- `danielgpinheiro/RSDKv3-xbox` is an archived Xbox-specific fork with NXDK instructions; it is recorded as a source port of the Retro Engine decompilation, not as a binary recompilation. `caorthann-celt/RSDKv4-UWP` is a distinct UWP wrapper for the Sonic 1/2 (2013) decompilation.
- `PerfectDarkRemasterRecomp` identifies the 2010 Xbox 360/XBLA game and title ID 584109C2, but its README input section says “Xbox One ISO.” That source inconsistency is included in the status so users verify their dump before relying on it.
- The Rayman Origins row uses the accessible `XDanfr/RaymanOriginsRecomp` source and its device/status documents. A legacy `BelmanteGu/RaymanOriginsRecomp` URL was inaccessible during research; the current record does not rely on it. No GitHub release was listed.
- The NFS Carbon repository’s name mentions Android, and its README confirms Android ARM64/Vulkan plus a Windows x64 prototype. GitHub classifies JavaScript as its primary language even though its described game recompilation generates C++; the language field reflects that repository metadata.
- `crazyriddler/Conan2007Recomp` is included with unclear status: the README supports a ReXGlue/D3D12 recompilation, but does not document a release or test boundary. GitHub identifies HLSL as its primary repository language.
- The WWE SVR07 row uses the upstream `HollywoodAkeem/SVR07-Recomp` repository and release, not the `AethonBolt` fork, to avoid treating a fork as a second project. A second GitHub search round added the Deathrow/Exonerated, Full Spectrum Warrior: Ten Hammers, FlatOut, L.A. Rush, and Halo CE incremental-reimplementation candidates. Their records state the current limits: no Deathrow binary release, the FSW world renderer is not finished, FlatOut has not statically recompiled retail game code, L.A. Rush remains early analysis, and Halo CE’s README conflicts with its linked 0.00% progress report.

Excluded candidates were general-purpose emulators/recompilers (not game-specific targets), sources already staged in sibling lanes, and entries without enough evidence to call them distinct and currently public game projects. The second-round search also excluded empty placeholder repos (`MiddleDucky/HP-COS-Xbox-Recomp` and `MiddleDucky/HP-PS-Xbox-Recomp`), a generic toolkit (`nemonicicon/ts3FPrecomp`), a ReXGlue compatibility component (`TheBiemGamer/skylanders-portal`), the unrelated AC6 module migration (`Project-Gracemeria`), and After Burner Climax, which lacked a title-specific release or source folder. These are source-backed discovery batches, not a claim that every Xbox project on the internet has been found.
